The API Function Index provides an alphabetical list of public UDUNITS-2 C API
functions for quick reference. Each entry links to detailed documentation
including the function prototype, description, parameters, return values, and
related functions.

Functions from the deprecated [UDUNITS-1 Legacy API](udunits-1-legacy-api.html)
are listed separately and are retained for reference only.
